A bookmark is a name attached to a place in the document: some text, a table cell, or a frame. Cross-references and some fields refer to bookmarks by name.

## Using the Bookmarks panel

1. Select the text, cell, or frame, or just place the caret.
2. Choose Edit › Bookmarks… (Ctrl+Shift+F5). The panel opens in the rail.
3. Type a name with no spaces and press **Add**.

Choose a name in the list and press **Go To** to select that place, or **Remove** to delete the bookmark. Bookmarks cannot nest. The panel also has a button that inserts a cross-reference to the chosen bookmark.

## Seeing them

View › Show › Bookmarks draws thin grey brackets at the ends of a bookmarked text, and an outline around a bookmarked cell or frame. They never print.

The References rail panel holds both bookmarks and notes, so F1 there opens this topic.
