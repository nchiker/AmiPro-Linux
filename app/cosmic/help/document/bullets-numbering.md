Format › Bullets and Numbering › Bullets (Ctrl+Shift+L) and Numbering (Ctrl+Shift+N) turn paragraphs into list items. Both are also buttons in the action bar and in the text right-click menu.

## How they work

A list is not a separate feature. The commands give the paragraphs a **list style**: a bullet style for Bullets, a numbered style for Numbering. If the document has none, the command makes one, named Bullet 1 (or Bullet, List Bullet) and Number List (or Numbered List, List Number), using the Body Text font and spacing. You can then edit that style like any other.

- The menu item is checked when every selected paragraph's style shows that kind of list. Choosing it again takes the list off.
- Numbers count the paragraphs in an unbroken run of the style and restart after something else intervenes.
- Pressing Enter in an empty list item ends the list by turning it into Body Text.

The status bar names the style that was applied. The commands are disabled while a frame is selected rather than its text.
