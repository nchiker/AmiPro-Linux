Format › Caps has four choices for the selected text: Upper Case, Lower Case, Initial Caps, and Small Caps. Each is a toggle with a check mark, like Bold.

## What each does

- **Upper Case** shows every letter as a capital.
- **Lower Case** shows every letter as a small letter.
- **Initial Caps** capitalises the first letter of each word.
- **Small Caps** draws lower-case letters as reduced capitals and leaves real capitals full size.

With only the caret showing, the choice applies to the text you type next, as it does for [Bold and Italic](bold-italic-underline).

## Style or direct

A whole style can set the same four in Style Properties › Font, where the list is called Caps and also has Normal. Use that when every paragraph of a kind should be capitalised, such as headings. Caps set on selected text is direct formatting, and [Normal](clear-direct-formatting) clears it.

Caps are an attribute of how the text is shown: the letters you typed stay as typed underneath.
