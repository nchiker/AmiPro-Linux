Format › Styles › Create Style… makes a new paragraph style. It does not apply the style to any paragraph; use [Select a Style](select-style) for that.

## The dialog

- **Name** is the new style's name. A name already in use, letter case aside, disables Create and says why.
- **Style** makes the new style a copy of a style picked from the list. The list starts on the caret paragraph's style.
- **Selected text** makes it from the caret paragraph's style with the direct paragraph formatting that paragraph has, so you can format a paragraph by hand and then turn it into a style.
- **Create** makes the style and closes the dialog.
- **Modify** makes the style and opens it in Style Properties at once.

## Afterwards

The new style is stored in the document, marked with a bullet in the style list. It takes the next free function key if one is left. Save it with [Save as a Style Sheet](save-style-sheet) to use it in other documents. The Styles panel's header has a + button and its rows have a menu with Create Style Based on This….

Saved as an Ami Pro document, style names are limited to 13 characters; see [Styles and style sheets](styles).
