File › Document Properties… (Alt+Enter) opens the Document Properties panel in the rail. Its facts can be shown in the text with **Document info** fields.

## The panel

- **Description** and **Keywords** (the description is limited in length).
- **Fields**: eight user fields with names you can edit in place.
- **Statistics**: pages, words, characters, and size, counted as you type ([Word count and statistics](word-count)).
- **History**: when the document was created and last saved, the number of revisions, and the editing time.

## Putting a value in the text

Open Insert › Field… and choose the **Document info** page. It lists about twenty entries with their values now, among them file name, path, style sheet, description, dates, statistics, and the user fields. Pick one and press Insert. A change made in the panel reaches fields when they are updated ([Updating fields](field-updating)).
