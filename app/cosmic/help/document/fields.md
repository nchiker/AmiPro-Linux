A **field** is a place in the text whose content is worked out: the date, the page number, a figure number, or a value from the document's properties. Ami Pro calls the programmable ones **power fields**.

## Inserting and editing

- **Insert › Field…** opens the Fields panel in the rail. Pick a kind of field and fill in its settings.
- **Insert › Date/Time…** puts in the current date or time.
- **Insert › Page Number…** puts in a page number field.
- Right-click a field, or use Edit › Power Fields › Edit Field, to change it.

## Keeping them current

- **Update Fields** (F9) refreshes fields; **Update All Fields** (Ctrl+F9) refreshes every field in the document.
- **Lock Field** stops a field from changing.
- **Next Field** and **Previous Field** step from one field to the next.

## Seeing them

View › Show has **Show Power Fields**, which shows the field's code instead of its result (Alt+F9), and **Field Shading**, which tints fields so they stand out.

## Document properties

File › Document Properties… (Alt+Enter) holds the title, author, description, and similar facts that Doc Info fields show. It opens in the rail.
