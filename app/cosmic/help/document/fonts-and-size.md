Format › Font… sets the typeface, point size, and colour of the selected text, or of the text you type next when nothing is selected. The right-click menu in text has it too.

## In the dialog

- **Face** lists the font families installed on this computer plus the faces the document's styles already use, so a document from another machine still shows its own names.
- **Size** offers a list of common sizes; you can type any size from 1 to 999 points.
- **Colour** is a row of fifteen swatches. If the selected text has a colour outside them, that colour gets a swatch of its own.
- A preview, drawn on white paper, shows the choice before you accept it.
- **Revert to style** puts face, size, and colour back to what the paragraph's style says.

OK writes face, size, and colour together as one undo step. Choosing the same values the style already has still counts as direct formatting; use Revert to style if you want the text to follow the style again.

## When the face is missing

A document may name a face this computer does not have. The text is then shown in a substitute; the name in the document is not changed, so it prints correctly on a computer that has the face.

To change a face for every paragraph of a kind, change the [style](modify-style) instead of the text.
