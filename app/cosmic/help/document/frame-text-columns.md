A text frame is a small document of its own. Its text has the same styles as the main text and can be edited in place; its box has its own columns and margins.

## Typing in a frame

Select the frame and press Enter, or double-click it, to put the caret in its text. Esc steps back out to the frame, and Esc again, or a click in the main text, returns to the main text. While the caret is in a frame, the Styles panel applies styles to the frame's paragraphs.

## Columns and margins

Frame Properties › Columns and margins sets:

- **Columns (1–8)**, with **Gutter (in)** when there are two or more, **Balance columns**, and **Line between columns** with its own colour. A frame whose columns have been made uneven on the ruler shows an Even Columns choice.
- **Top**, **Right**, **Bottom**, and **Left margin** between the frame's edge and its text.

With the caret in a frame, the ruler edits the frame's columns and margins, not the page's.

## No linking

Text does not flow from one frame into another here. A frame shows only its own text, so size the frame to fit it, or use more columns. For text that runs across pages, use the main text with page layouts and columns: see [Page size, margins, and columns](page-size-margins-columns).
