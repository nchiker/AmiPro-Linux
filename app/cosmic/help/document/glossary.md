A glossary keeps pieces of text you use again, each under a short name, and puts them back on request.

## Making a record

Select the text and choose Edit › Mark Text › Glossary…. Type a name. The selection is stored under it in the glossary file.

## Using a record

Type the name and press Ctrl+K (Insert › Glossary Record…) to replace it with the stored text. If the caret is not at a known name, Ctrl+K opens the Glossary panel in the rail, where you can see the records with a preview and insert, rename, or delete them. An option, off by default, completes names as you type: the status bar shows what a typed name would expand to, and Tab takes it.

## The glossary file

The records live in a glossary file, in Ami Pro's format. The panel's **Data File…** chooses another one and **New…** makes a fresh one. Only a file that reads as a glossary is ever changed. Several documents can share one file.
