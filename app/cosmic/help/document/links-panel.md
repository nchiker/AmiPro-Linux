**Edit › Links…** lists the linked and embedded objects that a document holds, mostly ones that came in with an Ami Pro file. Each row shows the kind (OLE object, OLE link, or a linked frame), its source, and its status.

Selecting a row goes to its frame and selects it, so Frame Properties shows the object's details.

## Limits

The list is read-only. Updating, unlinking, or editing a link needs the program that made the data, and this program cannot run those. An object whose picture can be read is still shown and printed. An empty document says it holds no links.
