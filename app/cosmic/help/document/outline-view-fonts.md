**View › Outline › Use Outline Styles** (a checked item) changes how paragraphs look in Outline mode only. When it is on, each level is shown in a font suited to the view: level 1 in a large bold serif face, levels 2 and 3 in smaller serif sizes, and levels 4 and below, and body text, in a plain sans-serif face. The paragraphs keep their own styles; only the view is changed, and printing is not affected.

The choice is a preference kept for the program, so it applies to every open document. With it off, Outline mode shows each paragraph in its own style's font.

To change what a level is (its style, number format, or outline level), edit the style: see [Outline Numbering and outline levels](outline-styles) and [Styles](styles).
