Format › Styles › Save as a Style Sheet… writes the document's styles and page layout to a new Ami Pro style sheet (`.STY`), so new documents can start from them.

## Steps

1. Choose the command. The dialog suggests a **Description** taken from the document; edit it to something you will recognise in the New Document list.
2. Tick **With contents** to put the document's text, frames, tables, and pictures in the sheet as well. A new document made from the sheet then starts with them, which suits a letterhead or a form. Leave it off for styles alone.
3. Choose **Save…** and name the file with the system file chooser.

## Notes

The sheet can then be picked in File › New and in [Use Another Style Sheet](use-another-style-sheet). Put it in one of the style-sheet folders (Preferences › Folders) and it is listed there.

A `.STY` file you opened is never written over; saving always asks for a file. The document keeps its own styles after saving, so nothing in it changes.
