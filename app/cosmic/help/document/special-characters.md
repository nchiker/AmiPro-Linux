Insert › Special Character… shows a grid of the symbols, accented letters, and punctuation that a keyboard does not type directly.

## Using the grid

Click a character to insert it at the caret, or over the selection, as one undo step. The characters you inserted most recently appear first, sixteen of them, so repeated use is quick. Cancel closes the dialog without inserting anything.

## Which characters

The grid holds the characters of the Windows ANSI set above plain ASCII: accented letters, currency signs, the euro, curly quotes, dashes, daggers, and the like. They are stored in Ami Pro files as themselves, so a document saved from here shows them in Ami Pro too.

For a bullet that is drawn with the document's own shapes rather than a font character, use Insert › Bullet…; see [Bullet and number style](bullet-number-style).
