A **style** names a set of paragraph and character settings: font, size, spacing, alignment, indents, tabs, and numbering. Every paragraph has one, and changing the style changes every paragraph that uses it. A **style sheet** (`.STY`) is the collection of styles and page layouts a document starts from.

## Choosing a style

Use the style list in the action bar, the Styles panel in the rail (it is the rail's default), or Format › Styles › Select a Style (Ctrl+Y). Right-click a paragraph and use the style list there too.

## Changing styles

- **Modify Style…** (Format › Styles, or right-click in the text) opens the style's properties in the rail. Changes show on the page as you make them.
- **Create Style…** makes a new style from the paragraph you are in.
- **Style Management…** copies, renames, and deletes styles.
- **Use Another Style Sheet…** replaces the document's styles with those of a `.STY` file. **Save as a Style Sheet…** writes the document's styles to one.
- **Outline Numbering…** sets numbering for styles that have outline levels; see [Outline mode](outline-mode).

Style names can be up to 13 characters when saved as Ami Pro files; longer names are shortened and listed in the loss check. A `.STY` file you opened is never written over.

Direct formatting (bold on one word, say) sits on top of the style. [Text formatting](text-formatting) explains how to clear it.
