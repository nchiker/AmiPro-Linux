A **style** names a set of paragraph and character settings: font, size, spacing, alignment, indents, tabs, and numbering. Every paragraph has one, and changing the style changes every paragraph that uses it. A **style sheet** (`.STY`) is the collection of styles and page layouts a document starts from.

## Choosing a style

Use the style list in the action bar, the Styles panel in the rail (it is the rail's default), or Format › Styles › Select a Style (Ctrl+Y). Right-click a paragraph and use the style list there too. See [Select a Style](select-style).

## Changing styles

Format › Styles has each job as a command:

- [Create Style…](create-style) makes a new style from a style or from the paragraph you are in.
- [Modify Style…](modify-style) opens the style's properties in the rail, with changes live on the page.
- [Outline Numbering…](outline-styles) sets numbering for styles that have outline levels.
- [Use Another Style Sheet…](use-another-style-sheet) replaces the sheet the document follows.
- [Save as a Style Sheet…](save-style-sheet) writes the document's styles to a `.STY` file.
- [Style Management…](style-management) reverts, moves, and removes styles.

Style names can be up to 13 characters when saved as Ami Pro files; longer names are shortened and listed in the loss check. A `.STY` file you opened is never written over.

## Styles and direct formatting

Direct formatting (bold on one word, say) sits on top of the style. [Clearing direct formatting](clear-direct-formatting) returns the text to its style. Settings that repeat belong in the style: see [Text formatting](text-formatting).
