**View › Toolbar** shows or hides the action bar under the menu. Tooltips on its buttons give the command name and shortcut.

When the window is too narrow for all the buttons, the ones at the end move into a **More** menu, so put the buttons you use most near the start. [Customize Toolbar](customize-toolbar) changes the set.

Hiding the toolbar is remembered for the next start. Preferences › Toolbar has the same switch.
