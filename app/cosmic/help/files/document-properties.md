**File › Document Properties…** (Alt+Enter) opens the Document Properties panel in the rail. Changes show as you type, and each is one undo step.

## Sections

- **Description:** a short description (up to 119 characters) and keywords.
- **Fields:** eight named values that you can use in the text with Doc Info fields. Click a field's name to rename it.
- **Statistics:** pages, words, characters, and file size, counted as you type. Tools › Word Count opens the panel at this section.
- **History:** when the document was created and last saved, how many times it was revised, and the total editing time.
- **File:** the file name and folder, and the style sheet in use.

The figures are saved with the document, so fields in the text that show a word count or a date use them. See [Power fields](fields).
