File › Print Envelope… opens the Envelope panel in the rail and prints an address on an envelope.

## Setting up

- Pick the **envelope size**.
- Fill in the **return address**; tick **Print return address** if it should be printed.
- The **recipient** address is taken from the selection, or else the first address-like block of the document. If none is found the panel says so and you type it.
- **Feed and offsets** move the print on the paper to suit your printer.

You can print the envelope straight away, or save it as a PDF.

## Merging envelopes

**Merge Envelopes** prints one envelope per record of the document's data file (the one chosen in File › Merge…). The recipient lines are taken from the fields you name. See [Merge, labels, and envelopes](merge).

Messages: [Merge and envelope messages](merge-messages).
