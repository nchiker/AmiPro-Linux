**File › Page Setup…** is the File menu's way to the same panel as Format › Page Layout…: the Page Layout Properties panel in the rail. There is no separate dialog.

In it you set the paper size and orientation, margins, columns, tabs, and the header and footer, for the page layout in force at the caret. The printer itself is chosen in the desktop's print dialog, not here.

See [Pages, frames, and layouts](pages-frames-layouts) for what each setting does.
