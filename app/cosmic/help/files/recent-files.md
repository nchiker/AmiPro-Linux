The bottom of the File menu, above Quit, lists the documents you used last, numbered from 1. Choose one to open it.

The number kept is set in Preferences › General, **Recent files in the File menu**, from 0 to 9. Set it to 0 to keep no list.

A file that has since been moved or deleted fails to open with a message in the status bar.
