**File › Revert to Saved…** throws away what you changed since the last save and shows the file as it is on disk. It asks before doing anything.

The command is available only for a document that has a file and has unsaved changes. A new document that was never saved has nothing to go back to.

The revert is one step in the history, so Edit › Undo brings your changes back if you reverted by mistake.
