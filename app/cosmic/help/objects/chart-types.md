The **Type** section of the Chart panel has twelve icons in two rows of six, with the name under each.

| Type | Draws |
|---|---|
| Column | Vertical bars side by side for each category |
| Stacked Column | One column per category, series piled on each other |
| Bar | The same, horizontal |
| Stacked Bar | Horizontal stacks |
| Line | One line per series |
| Area | Lines with the area under them filled, series stacked |
| Line and Picture | Lines with a marker at each point |
| Line and Picture by Category | Lines where the marker follows the category |
| Pie | One circle, a slice per value |
| Expanded Pie | The slices drawn apart |
| Picture | Columns made of repeated pictures |
| Stacked Picture | Stacked columns made of pictures |

## Variations

Under the icons, two radio buttons switch between the members of a family without changing the data: Clustered or Stacked (columns, bars, picture), Lines or Areas, one marker per series or per category, Whole or Expanded.

## Pies

A pie uses only the first series. If the pie shows a single slice, the data is probably the wrong way round: use **Flip Data** ([Chart data](chart-data)). A pie has no axis.

## Pictures

The picture types draw their own markers; the panel says so. Ami Pro's list of pictures for the chart is not read and there is no Pictures button; see [Known limitations](known-limitations).

Some chart kinds are drawn from notes and have not been compared with Ami Pro's own drawing; a caution line in the panel says when that applies.
