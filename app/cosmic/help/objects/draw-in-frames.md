A frame holds exactly one thing: text, a table, or a picture. Drawings, charts and equations count as pictures, so each lives in a picture frame and not in the main text.

## What this means in practice

- **Insert › Drawing…** needs an empty frame, an empty table cell, or the caret in the main text (where it makes a new frame). For a frame that holds something else, the status bar says a drawing goes into an empty frame.
- A frame with a drawing keeps its size when you leave Draw mode. The art may be smaller than the frame; Fit Frame to Picture shrinks the frame around it.
- Placement, wrap and borders are ordinary [frame settings](pages-frames-layouts): a drawing can flow with the text, be anchored to a paragraph, or repeat on every page.
- Frames with drawings can be scaled and positioned like pictures: see [Graphics scaling](graphics-scaling).

## Charts and equations

A chart is a drawing in a frame, so Draw mode can edit it; see [How charts are stored](chart-storage). An equation is a picture drawn from its text and is edited in its own card; see [Equations](equations).
