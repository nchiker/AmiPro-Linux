A drawing can hold text objects. Choose the **Text** tool, click where the text should start, and type. Esc or a click elsewhere finishes. Double-click a text object to change its words.

The draw bar's Face, Size, Bold, Italic and Underline, and the Text section of [Drawing Properties](drawing-properties), set the font of the selected text objects; with none selected they set the font of the next one. Text can be coloured, turned and flipped like any object.

Pasting plain text while in Draw mode makes one text object for each paragraph.

For text that must flow with the document, use a text frame on the page instead; a drawing's text does not reflow. See [Pages, frames and layouts](pages-frames-layouts).
