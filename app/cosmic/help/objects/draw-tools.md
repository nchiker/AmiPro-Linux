The draw bar has ten tools. Hover a tool to see a tip that includes its Shift behaviour.

| Tool | What it does |
|---|---|
| Select | Click an object, drag a marquee around several, Shift-click to add or remove, Ctrl-click to select the next object below at the same point. |
| Hand | Moves the whole drawing inside its frame. |
| Line | Drag from end to end. Shift constrains to level, plumb or 45 degrees. |
| Polyline | Click each point; double-click to finish. Shift and drag draws freehand. |
| Polygon | Like Polyline, but closed and fillable. |
| Rectangle | Drag a corner to a corner. Shift makes a square. |
| Rounded rectangle | As Rectangle, with rounded corners. Shift makes a square. |
| Ellipse | Drag its bounding box. Shift makes a circle. |
| Arc | Drag its bounding box to make an arc. |
| Text | Click and type; see [Text in drawings](draw-text). |

After a shape is drawn the tool stays chosen so you can draw another; go back to the arrow to select.

New objects use the look set in [Drawing Properties](drawing-properties) with nothing selected.

## Keys

With objects selected: arrow keys nudge them (by the grid spacing when Snap is on, else a small fixed step), Shift multiplies by ten, Alt moves one screen pixel. Tab and Shift+Tab step through the objects, Delete removes the selection, Enter finishes a polyline or polygon, and Esc finishes the shape or leaves Draw mode.
