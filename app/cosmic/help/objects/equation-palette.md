The Equation panel in the rail is a palette of buttons in twelve groups. Each button has a tooltip and puts its template at the caret, or around the selected text. A `⬚` marks each place to type, and the first is selected so you can simply type.

| Group | Examples |
|---|---|
| Fractions | fraction, binomial, text and display size |
| Radicals | square root, root with an index |
| Scripts | superscript, subscript, both, prime |
| Sums, integrals, products | sum, product, integrals, union, intersection, limit, with or without limits |
| Brackets | parentheses, square, braces, angle, bars, floor |
| Matrices | 2 by 2, 3 by 3, bracketed, determinant, column |
| Over and under | bars, hat, vector, tilde, dot, braces, text over |
| Functions | trigonometric and other named functions |
| Greek | capital and small letters |
| Operators | plus-minus, times, set operators and so on |
| Relations | equals, order, membership |
| Arrows | the common arrows |

Below the palette: **Face and size**, and **Files and LaTeX** ([Equation files and LaTeX](equation-files)).

Ami Pro's separate Greek keyboard, Symbol keyboard, Math and Text mode, and Hide Matrix Lines options are not separate switches here; use the palette groups or type the control words ([TeX commands](equation-tex-reference)).
