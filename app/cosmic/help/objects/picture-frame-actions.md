The buttons at the bottom of the Picture section in Frame Properties:

- **Reset**: Fit in frame with the aspect ratio kept, 100 percent, not turned and not moved. This is how a picture is left when it is first inserted.
- **Replace Picture…**: opens the same chooser as Insert › Image…; the new picture goes in the same frame and keeps its placement and scaling.
- **Fit Frame to Picture**: resizes the frame around the picture as it is drawn, keeping the frame's margins, and moves the picture back to the frame's corner.
- **Save Picture As…**: writes the picture out as a file in its own format.
- **Description**: text that describes the picture. It is kept in the program's own files but Ami Pro files cannot store it.

The section's first lines say what kind of picture it is, its natural size, and, for a linked picture, the path of the file it is linked to. See [Inserting pictures](inserting-pictures) for linking.

For an embedded OLE object the section is called Object; see [OLE objects](ole-objects).
