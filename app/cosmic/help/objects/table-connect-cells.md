**Connect Cells** (Table menu) joins the selected rectangle of cells into one. The text of the cells that disappear is kept, hidden, and returns if you disconnect.

When the caret is in a joined cell, the same menu item reads **Disconnect Cells** and separates it again. The program has no separate Split command; a connected cell is divided with Disconnect Cells.

Connected cells cannot be sorted without separating them: the Sort panel asks first and Continue disconnects them ([Sorting](sorting)).

To get a different number of cells in a row, insert a column or row instead ([Rows and columns](table-rows-columns)).
