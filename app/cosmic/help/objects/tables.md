Insert › Table… (Ctrl+F12) asks for the number of columns and rows and makes a table at the caret. Type in a cell as in any text; Tab moves to the next cell.

## Changing the table

The Table menu works on the table the caret is in. It can insert and delete rows and columns, select a row, column, or the whole table, and connect cells into one. **Table Properties** opens the rail panel for sizes, lines, and shading. Drag a grid line to resize. **Table Style** gives a table a ready-made look. **Distribute Rows Evenly** and the matching columns command even them out. **Convert Text to Table** and **Convert Table to Text** convert between a table and tab-separated paragraphs.

## Calculating

**Edit Formula…** puts a formula in the current cell, for example a sum of the cells above it. **Quick Add** (Row or Column) totals a row or column in one step. **Recalculate Table** updates every formula. Number formats show through the cell's style.

## Sorting

**Tools › Sort…** and Sort Ascending and Descending in the Table menu sort rows by one or more columns.

A table that is longer than a page continues on the next page, and its heading rows can repeat. A table may sit in the text or inside a frame.
