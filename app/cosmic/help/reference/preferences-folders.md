The Folders page has two parts.

## Documents

The folder where Open, Save As, Insert File, Import, Export, and Insert Image start when the document has no folder of its own. **Choose…** picks one; once one is set, **Use the Desktop's Default** below it goes back to the desktop's own. A long folder name is shortened in the middle; point at it to see it whole.

## Style-sheet folders

The folders searched for a document's style sheet, and listed by File › New… and Format › Use Another Style Sheet. **Add Folder…** adds a folder and **Remove**, on its row, takes one off. A folder given by the `AMIPRO_STYLES` environment variable is listed first, with a note saying so and no Remove button: it is always searched and can only be changed outside the program.
