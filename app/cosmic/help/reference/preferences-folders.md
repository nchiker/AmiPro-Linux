The Folders page has two parts.

## Documents

The folder where Open, Save As, Insert File, Import, Export, and Insert Image start when the document has no folder of its own. **Choose…** picks one; **Clear** goes back to the desktop's default.

## Style-sheet folders

The folders searched for a document's style sheet, and listed by File › New… and Format › Use Another Style Sheet. **Add…** adds a folder and **Remove** takes one off. A folder given by the `AMIPRO_STYLES` environment variable is shown too, marked with that name; it can only be changed outside the program.
