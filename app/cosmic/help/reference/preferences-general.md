The General page holds these settings, in four sections.

## New documents

- **Style sheet File › New… selects first**: a file name such as `_DEFAULT.STY`. Ctrl+N also starts from it.
- **Save new documents as**: Ami Pro (.SAM, the default), Native (.amipro), or Markdown (.md). A document with no file yet is offered that name and type in Save As; a document that already has a file keeps its own type. Markdown goes through Export's loss list before anything is written.

## Saving

- **Keep the original as NAME.SAM.bak**: the first save over an Ami Pro file keeps the old copy. See [Saving and Ami Pro files](saving-files).
- **Keep recovery copies while editing**, and, while it is on, how often to write one: 1, 2, 5, or 10 minutes. See [Crash recovery](crash-recovery).

## Editing

- **Undo levels** (1 to 1000): how many steps Undo can go back.
- **Recent files in the File menu** (0 to 9).

## Updates

- **Check for updates when the program starts**: at most once a day; see [Updates](updates).

A number you type outside its range is refused with a message showing the allowed range. The custom zoom is on the [View page](preferences-view).
