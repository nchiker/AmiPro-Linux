The General page holds these settings.

- **Undo levels** (1 to 1000): how many steps Undo can go back.
- **Custom zoom (%)** (25 to 400): the percentage View › Custom Zoom uses.
- **Recent files in the File menu** (0 to 9).
- **Style sheet File › New… selects first**: a file name such as `_DEFAULT.STY`. Ctrl+N also starts from it.
- **Keep the original as NAME.SAM.bak**: the first save over an Ami Pro file keeps the old copy. See [Saving and Ami Pro files](saving-files).
- **Check for updates when the program starts**: at most once a day; see [Updates](updates).
- **Keep recovery copies while editing**, and how often to write one: 1, 2, 5, or 10 minutes. See [Crash recovery](crash-recovery).

A number you type outside its range is refused with a message showing the allowed range.
