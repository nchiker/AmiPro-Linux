The View page has a switch for each part of the window and each mark that View › Show offers: Toolbar, Ruler, Field shading, Notes, Bookmarks, Tabs & Returns, Column guides, Margins in colour, Pictures, and Table row/column headings. They are the same switches as in the View menu, so changing one in either place changes both.

In the plain text-editor build, only the toolbar switch is offered.

See [Showing marks and guides](show-marks) for what each mark does.
