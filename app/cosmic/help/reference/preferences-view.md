The View page has three sections.

- **Window**: a switch for each part of the window that the View menu shows or hides: Toolbar (with **Customize Toolbar…** beside it), Ruler, Vertical ruler, and Status bar.
- **Zoom**: **Custom zoom (%)** (25 to 400), the percentage View › Custom Zoom uses; the menu item shows it.
- **Show on the page**: a switch for each mark of View › Show, in the menu's order: Tabs and returns, Column guides, Margins in colour, Pictures, Table row/column headings, Field shading, Notes, and Bookmarks.

They are the same switches as in the View menu, so changing one in either place changes both.

In the plain text-editor build, only the toolbar switch is offered.

See [Showing marks and guides](show-marks) for what each mark does.
