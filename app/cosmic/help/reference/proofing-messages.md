The messages below appear in the Proofing panel or the status bar.

## Spelling

- **Loading the dictionary…** The dictionary is read in the background the first time. Wait a moment.
- **No spelling dictionary is installed for (language).** The panel names a package. Install it with your system's package manager, restart if the language does not appear, or choose another language in the list. American English always works.
- **No words were found to correct.** The range you checked is clean, or nothing is selected that can be checked.
- **Spell check complete.** The check reached the end. It does not wrap around; start again from the top of the document to check earlier text.

## Thesaurus

- **Loading the thesaurus…** Wait for the word list to be read.
- **No thesaurus is installed for (language). Install a mythes package for it.** Install the MyThes package for that language, or change the document's language.
- **Click on a word to look up and try again.** The caret was not in a word. Click inside one, then open the Thesaurus again.

## Grammar

- **Grammar Check is available for English documents only.** Change the language to an English form, or use only spelling.
- **Loading the grammar checker…** Wait a few seconds; the first load is slow.
- **No problems were found.** and **Grammar check complete.** Nothing more to do.

## Alternatives

- **No alternative found.** The checker had no suggestion. Type the correction in the Replace with box.
- **No words added yet.** Your user dictionary is empty.
