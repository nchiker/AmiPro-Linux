These are the messages shown while you build a table of contents or an index, and what each one asks of you.

## Table of contents

- **No TOC entries: give a style a level, or mark entries on the Entries page.** Nothing qualified. In the panel's contents section add a paragraph style at a level, or mark text ([Marking entries](marking-entries)).
- **No style is a TOC level yet.** Same cause; the panel shows it before you generate.

## Index

- **No index entries: mark them on the Entries page.** Nothing has been marked. Select a word and use Edit › Mark Text › Index Entry….
- **Must specify a primary.** The mark needs a first-level entry. Type one.

## Glossary

- **That file exists: choose it with Data File…** New… will not overwrite a file. Use Data File… to open the existing one, or choose another name.

For the same messages across a master document, see [Master document messages](master-documents-messages).
