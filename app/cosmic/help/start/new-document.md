There are two ways to start a document: a blank one from the default style sheet, or one made from a style sheet you pick.

## A blank document

**File › New Document** (Ctrl+N), or the plus button after the last tab, opens an empty document in a new tab. It uses the style sheet named in Preferences › General (`_DEFAULT.STY` unless you changed it).

## From a style sheet

**File › New…** opens a dialog with the style sheets found in your style-sheet folders. Each is listed by its description, or by file name if you turn off **List by description**. The sheets you used lately come first, under **Recent**; the rest follow under **All style sheets**. Select one to see a miniature of its first page, then press **Create**.

Some sheets carry ready-made text and layout, such as a letterhead. **With contents** decides whether that text comes with the new document or only the styles do.

If the list is empty, add a folder in [Preferences](preferences-folders) › Folders.

The new document has no file name until you save it. See [Saving and Ami Pro files](saving-files).
