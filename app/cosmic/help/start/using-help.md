Help opens in the rail, beside your document, so you can read and work at the same time.

## Ways in

- **F1** (Help › Help) opens the topic for what you are doing: the panel that is open, the kind of frame that is selected, the find bar, a table, or Outline mode. If there is none, it shows the contents.
- **Help › Help Contents** lists the topics by area.
- **Help › Search Help…** puts the cursor in the search box. Type words; a topic matches when every word is found in its title, keywords, or text. Titles rank first.

## Moving around

- An underlined name in a topic is a link to another topic. **See also** at the end lists related ones.
- **Back** and **Forward** (the arrows at the top) retrace the topics you have read. **Contents** returns to the list.
- Esc closes the panel. It reopens at the topic where you left it.
