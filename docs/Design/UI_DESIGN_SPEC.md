The earlier document established the useful document-centered direction—menus,
one compact toolbar, tabs, Styles panel, ruler, page workspace, and status—but
it is superseded because it did not specify a complete command inventory,
visible shortcuts, measurable screen geometry, toolbar icon states, or a single
owner for style workflows. It also described simultaneous toolbar, status-bar,
and panel style selectors that contributed to the duplicated controls rejected
in physical review.

Do not implement from historical copies of this document. The canonical set
above preserves its valid safety, page-workspace, tab-isolation, and native
COSMIC goals while resolving the 2026-10-09 acceptance failures.
