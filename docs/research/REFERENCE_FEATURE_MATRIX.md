# Reference Feature Research Matrix

This is the decision-oriented companion to `FEATURE_PARITY.md`. It identifies
what must be learned before major implementation work; it does not itself claim
feature parity. Apply `docs/REFERENCE_DRIVEN_DEVELOPMENT.md` to each row.

## Decompilation

Decompiling and disassembling the reference binaries is authorized as broadly
as the work needs (user authorization, 2026-10-11; see `AGENTS.md`). Use it
where it answers a question more reliably than documentation, VM behavior, or
corpus variation, for example the meaning of a SAM record field. Record the
binary and version identifier, the question, observations at a behavioral
level, and the resulting independent design decision. Keep decompiler projects
and output outside this repository, and do not export decompiled listings or
proprietary constants/resources into it.
